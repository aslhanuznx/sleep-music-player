# 😴 Eye Tracking Sleep Detector

This project is a real-time eye tracking application developed with Python. It uses the computer's webcam to monitor the user's eyes and automatically plays an alarm sound when the eyes remain closed for a certain period of time.

## 🚀 Features

- 👁️ Real-time eye tracking
- 🎵 Automatic alarm when the eyes stay closed
- 📷 Webcam support
- ⚡ Face and eye detection using MediaPipe Face Mesh
- 📊 Live status information

## 🛠️ Technologies Used

- Python
- OpenCV
- MediaPipe
- Pygame

## 📦 Installation

```bash
pip install -r requirements.txt
```

## ▶️ Usage

```bash
python main.py
```
